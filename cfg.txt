Color reference : n for black (/none), r for red, g green, b blue, y yellow, m magenta, c cyan, w white.
Note that this is in 8 bit mode for plain compatibility with all terminals.

1 = path to system application
2 = path to user applications
3 = path to system icons (icons system to be implemented (not sure if I will))
4 = path to user icons
5 = color
6 = highlight color
